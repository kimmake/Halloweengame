# 할로윈 파티 준비

어르신을 위한 두뇌 건강 미니게임 「기억마을」의 할로윈 버전이에요.
마을 사람들과 함께 오늘 밤 할로윈 파티를 준비하면서 기억력·주의력·판단력을 자연스럽게 사용해요.

- 마우스 클릭(또는 손가락 터치)만으로 모두 플레이할 수 있어요. 키보드는 필요 없어요.
- 게임마다 25초 안에 끝내 보는 타이머가 화면 위에 있어요. 시간이 끝나도 "한 번 더 하기"로 바로 다시 할 수 있고, 틀려도 "다시 한번 생각해볼까요?"처럼 부드럽게 안내해요.
- 마을을 누르면 주인공이 그 장소 앞까지 걸어가요.

## 게임

| 장소 | 게임 |
|---|---|
| 우리집 | 파티 갈 준비하기 · 할로윈 짝꿍 찾기 |
| 우체국 | 초대장 번호 기억하기 |
| 시장 | 할로윈 장보러 가기 |
| 버스정류장 | 파티장 버스 타러 가기 |
| 공원 | 무엇이 달라졌을까요? |

- **오늘 하루:** 파티 준비 세 가지가 하나의 이야기로 이어지고, 마지막에 파티 약속 시간을 떠올려요.
- **게임 골라하기:** 게시판에서 원하는 게임을 바로 고를 수 있어요.
- **소리:** 마을에서는 잔잔한 할로윈 음악이, 게임을 시작하면 신나는 게임 음악(러시아 민요 「코로베이니키」를 새로 편곡)이 나와요. 화면 위 "소리" 버튼에서 배경음과 효과음을 크게 / 보통 / 작게 / 끄기로 고를 수 있어요.

## 실행하기

`index.html` 파일 하나에 모든 것이 들어 있어요. 더블클릭하면 브라우저에서 바로 실행돼요.
휴대폰에서는 가로로 돌려서 하는 것을 권장해요.
